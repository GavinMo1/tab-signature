# 实现说明

## 界面

产品名「签名」，图形为带编辑光标的标签页。底色白 `#ffffff` 与浅蓝灰 `#f3f6fa`，主文字 `#24333f`，辅助文字 `#637280`，操作蓝 `#255acf`，错误红 `#ae2636`。使用微软雅黑 UI / 微软雅黑等本机无衬线字体，不请求网络字体。

弹窗宽 380px，顺序为当前状态与原标题、名称输入、保存和恢复、网址规则入口。规则页采用单个编辑区与横向规则列表，不做仪表盘。界面左对齐，键盘可聚焦，状态使用 aria-live，删除有原生 dialog 确认。

## 状态和优先级

- `storage.local.rules`：长期保存 `{id, type, url, name, enabled}`；type 为 exact/prefix/domain/wildcard，旧数据缺少 type 时按 exact 处理。读取派生无效行，不改写历史数据；所有修改通过原始数组 SHA256 revision 和 index 定位，过期快照拒绝。
- `storage.session['tab:<id>']`：`{url, manual}` 或 `{url, ignored: true}`，关闭标签页删除，浏览器会话结束后清空。
- 手动命名 > 临时忽略 > 按数组顺序首条启用且命中的规则 > 网页自身标题。编辑保留位置，上下移动后立即重新匹配所有标签页。
- 域名规则精确比 hostname，申请该主机 HTTP/HTTPS 两种权限；通配符只允许固定协议和主机，按 * 分段转义正则后锚定全 URL，其他正则元字符不解释；前缀额外验证 origin 相同。
- 每次按实际 `tabs.get()` 的 URL 判断；URL 不同的旧手动状态直接失效。
- 规则变更和权限注册串行执行；页面同步及手动写操作按 tabId 分别串行。queued 请求合并，running 请求标 dirty，结束后排到队尾补跑；后台最多3路。冻结或丢弃时记录 deferred，恢复或激活触发检查，worker 重启不依赖旧内存集合。手动操作独立于后台全局并发队列。
- 弹窗状态和规则列表读取不进入写入队列。弹窗直接读取 tabs、本机会话及规则存储；原标题只作补充查询，等待最多 100ms，不注入脚本、不触发全量同步。
- 页面应用消息等待最多 1000ms，补注入等待最多 1500ms；界面请求设 8 秒超时，读取失败会更新状态标签，避免永久停在“正在读取”。全量同步只派发各页面任务，不等待所有页面响应后再回复保存操作。

## 页面执行

按已授予的 HTTP/HTTPS 主机权限动态注册 `document_start` 内容脚本，支持浏览器重新启动后的自动规则。对已打开页面按需补注入；脚本是幂等的，不重复安装观察器。

内容脚本只在顶层框架执行。仅当自定义名称生效时观察 head 子树及 document / html 的直接子节点，未命名或恢复时断开观察；从源头不接收正文子树的变更记录。标题写入时暂时断开自身观察器，纠正使用单个 50ms 定时器，避免与网站观察器在微任务队列相互触发。后台跳过 discarded / frozen 页面，不给无需命名且没有现存代理的页面补注入。记录最近的网站标题，后台同时监听 tabs URL 与 History API / hash 导航事件。应用消息携带 URL，页面已跳转时拒绝旧消息。

权限撤销时注销旧的动态脚本、重新注册剩余范围，向已有内容脚本发送恢复消息；保留规则并标注授权缺失。消息只接受本扩展，内容脚本仅可发送 ready，不可管理规则或修改其他标签页。

## 测试策略

v1.1.4 通配符采用字面分段 KMP，避免多个星号的正则回溯。历史 domain 星号不参与匹配或授权。页面 apply 消息携带 storage.session 单调序号，内容脚本拒绝迟到的旧序号；后台重启后序号继续递增。规则列表依赖派生行定位，不再使用重复 id 的全表 map/filter 修改；无效对象停用只改 enabled，primitive 可修正或删。弹窗初始禁用与状态守卫，列表读取代次和操作后焦点恢复防止旧响应和重绘破坏输入。

核心测试验证 URL 规范化、精确匹配、Unicode 名称、优先级和规则重复校验。浏览器测试在本机 Chrome 的隔离配置中加载真实扩展，操作真实弹窗及管理页，验证多标签页、刷新、动态标题、SPA 导航、规则 CRUD、窗口移动、复制、关闭清理、后台重启及浏览器重启。

网站授权弹窗由 Chrome 自身呈现；自动化只预授权本地测试主机，并另外检查未授权主机不会报告命名成功。真实权限弹窗样式和用户点击路径不计入自动化通过声明。
